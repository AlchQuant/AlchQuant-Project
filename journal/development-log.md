# Development log

The work on AlchQuant, in chronological order. Each entry records
what was done and what was decided at the milestone level.
Implementation details are not recorded here.

## November 2026

The program begins. Design versions are specified, implemented,
tested, and independently reviewed, one at a time. Every review
verdict is PAPER/SHADOW ONLY.

## 24 November 2026

- Draft v31 completed and verified. Independent review (round 26)
  concludes PAPER/SHADOW ONLY.
- A readiness review concludes the program is not yet ready for a
  first paper run. Work continues on the readiness gate.
- Draft v32 completed and verified. Independent review (round 27)
  concludes PAPER/SHADOW ONLY.
- Draft v33 completed and verified. Independent review (round 28)
  concludes PAPER/SHADOW ONLY.

## 25 November 2026

- Draft v34 completed and verified. Relay sent to four independent
  reviewers for the next review round.
- Public documentation begins: the AlchQuant-Project repository is
  created, and the README, philosophy, architecture, roadmap, and
  changelog are published.
